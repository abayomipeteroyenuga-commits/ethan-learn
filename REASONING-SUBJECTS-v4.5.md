# ETHAN Learn v4.5 — Reasoning & Calculation Subjects

The Mathematics teaching procedure is now extended conceptually to reasoning/calculation subjects rather than treating them as reading-only content.

Applied subject-aware flows include:
- Accounting / bookkeeping / auditing / taxation / cost and management accounting
- Economics
- Commerce / Business Studies / banking / insurance / office practice
- Finance / business mathematics
- Logic / critical reasoning
- Physics / Chemistry / Biology / Science / selected data-analysis courses

Standard flow:
Subject → Topic → Explanation → Rule/Method → Worked Example → Guided Practice → Independent Work → Real Practical/Case → Quiz → Mastery Check.

Accounting has a dedicated numerical Accounting Equation / Double Entry worked lesson. Other topics receive subject-aware reasoning/practical scaffolds; these should continue to be replaced progressively by bespoke topic-by-topic numerical/case question banks for textbook-level depth.
