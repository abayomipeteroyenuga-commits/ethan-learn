# ETHAN Learn v4.0 — Expanded Academic + Active Learning

## Benchmark-informed improvements
The learning UX was benchmarked against patterns used by major learning platforms:
- mastery practice, hints, quizzes and unit-style checking;
- interactive/practical application rather than text-only consumption;
- projects and graded-style evidence;
- resume/progress/offline access;
- multimodal lesson support, including listening.

ETHAN Learn implements these ideas in its own UI and code rather than copying another platform.

## New academic catalog
123 additional courses were added across:
- Sciences
- Arts & Humanities
- Commercial Studies
- Business
- Literature

New dedicated subject hubs were added for Arts & Humanities, Commercial Studies and Literature.

## Active learning
Every lesson can now include a generated `Do It Now` practical with:
- a concrete task;
- a worked-process prompt;
- a stretch challenge;
- evidence to keep;
- learner reflection;
- saved practical-evidence state.

Quizzes now include hints and stronger mastery feedback.

## Brand
A new ETHAN Learn mark combines an open book, progress/growth arrow and the established navy/blue digital identity. PWA icons were regenerated from the new mark.
