# ETHAN Learn v4.4 — Mathematics Teaching Procedure

All Mathematics courses now carry the explicit learning sequence:

Subject → Topic → Explanation → Formula/Rule → Worked Example → Guided Questions → Independent Questions → Real Practical → Quiz → Mastery Check.

This is intentionally aligned with the teaching/evaluation style used in Nigerian curriculum materials. For example, NERDC's JSS3 simultaneous linear equations curriculum expects learners to work with tables/graphs, elimination, substitution and real-life applications, not merely read a definition.

Simultaneous Equations is now explicitly organized into meaning, graphical method, elimination, substitution, guided practice, independent questions, exam technique and quiz/mastery.

The same visible procedure is applied to Mathematics courses. Dedicated topic-specific worked banks should continue to be expanded for each major topic so generic practice prompts are progressively replaced with fully numeric/symbolic authored questions.
