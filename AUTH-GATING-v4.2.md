# ETHAN Learn v4.2 — Sign-in Required Learning

Learning access is now account-gated.

Visitors may browse the public home page, subjects, curriculum overviews and course discovery pages.

A signed-in Supabase account is required for:
- opening a course learning page
- lessons
- My Learning
- Practice
- Dashboard
- Library
- Teacher area
- Profile and Settings
- Certificates

If a signed-out user tries to open a protected route, ETHAN Learn redirects them to Sign In and remembers the page they wanted. After successful sign in, they are returned to that page.

This is authentication gating. Paid subscription gating can be added separately later.
